# مسودة: تيرمينال شام الحي — للمراجعة لاحقاً (لم يُقرَّر بعد)

> حالة: **مسودة للنقاش**. لا يُنفَّذ منها شيء قبل قرار المالكة.
> آخر تحديث: 2026-09-30

## الهدف
أن تعمل دورة **الزحف ← الجمع ← الترميز ← التدريب ← الحفظ** بنفسها ومن دون تدخل، **خارج Kaggle ونظام الدفاتر**.
**نحن** نكتب الكود ونتحكم بالتشغيل، وليس شام.

## الفكرة كما طرحتها المالكة
1. **القسم الأول:** نضع خلية المهندس (بعد تطويرها) داخل كود شام كبرنامج واحد، ونشغّله من تيرمينال، فيعمل وحده حتى الحفظ.
2. **القسم الثاني:** نشغّل البرنامج نفسه من GitHub كمشغّل بدل Kaggle.
3. **اقتراح إضافي:** صفحة مخفية في موقع سوق تولز (Vercel) فيها تيرمينال متصل بشام.

## التحليل

### Vercel
- دوال Vercel تعمل ثوانٍ إلى دقائق لكل طلب، ثم تتوقف.
- حجم الكود المسموح لا يتسع لـ PyTorch، ولا لنقطة حفظ شام (حوالي 430MB).
- لا يوجد GPU ولا قرص دائم.
- **النتيجة:** لا يدرّب شام هناك، لكنه يصلح **لوحة تحكم**: أزرار تشغيل وإيقاف، والحالة، والسجل، والنتائج.

### GitHub Actions (المحرّك المقترح)
- **المستودع `jonsnow-org/Ttbik` عام (Public)** (تحقق 2026-09-30)، لذلك دقائق Actions مجانية بلا حد.
- الأجهزة: 4 معالجات و16GB ذاكرة، وحتى 6 ساعات لكل تشغيل. **لا GPU.**
- الدورة الحية:
  - ملف تشغيل كل 6 ساعات، كل تشغيل يعمل حوالي 5.5 ساعات ثم يحفظ ويسلّم للتالي؛
  - لا يعمل تشغيلان في الوقت نفسه؛
  - زر تشغيل يدوي، أو أمر من لوحة Vercel عبر GitHub API.
- **تنبيهات:**
  - التدريب على معالج عادي أبطأ بكثير من GPU في Kaggle (تقديرياً 50 إلى 100 مرة، لم يُقَس بعد). الزحف والجمع والترميز سريعة هناك.
  - إن صار المستودع خاصاً، تصبح الدقائق المجانية حوالي 2000 دقيقة شهرياً.
  - كون المستودع عاماً يعني أن كود شام مرئي للجميع.
- **جرّبناه سابقاً:** تشغيل دفاتر Kaggle من الخارج عبر الـAPI لا تصلها الأسرار. لذلك يعمل المحرّك على GitHub نفسه ولا يشغّل Kaggle.

### الحفظ خارج Kaggle
| الخيار | المزايا | العيوب |
|---|---|---|
| GitHub Releases | الأبسط، ومجاني، وحتى 2GB للملف | عام مثل المستودع: أوزان شام متاحة للجميع |
| Cloudflare R2 (المرشّح) | خاص، وسريع، وتنزيله مجاني، و10GB مجاناً | يحتاج حساب Cloudflare ومفتاحاً في أسرار GitHub |
| Kaggle Datasets | خاص ويعمل الآن | يبقينا مرتبطين بـ Kaggle |

- **نقل ما تحقق سابقاً:** برنامج ينقل مرة واحدة آخر نسخة من كل مرحلة من Kaggle إلى المخزن الجديد، ثم يستأنف كل شيء من هناك.

### ما يتحكم به شام نفسه (لاحقاً فقط)
- **لا تيرمينال حر للنموذج:** قدرته الآن لا تكفي، ويوجد خطر أمني لأن المفاتيح في البيئة.
- **الممكن لاحقاً:** أفعال متعلَّمة محدودة (اجمع عن موضوع، درّب، قِس، احفظ) ينفّذها منفّذ آمن. تبقى نائمة حتى يثبت القياس جاهزيتها، مثل مرحلة GRPO.

## الخطوة الأولى التي نُفّذت (منفصلة عن هذه المسودة)
- وحدتا `sham_spider.py` و`sham_live.py` ودفتر `sham_live_trainer.ipynb`. هذا هو البرنامج الحي نفسه، ويعمل اليوم على Kaggle.
- **يمكن نقله لاحقاً إلى GitHub Actions بلا تغيير في الكود:** يلزم فقط مكان حفظ بديل لـ `publish_dataset` و`fetch_dataset`.
