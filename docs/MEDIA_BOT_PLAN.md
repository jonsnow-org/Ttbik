# خطة بوت تحميل الوسائط المتقدم (Media Download Bot)

**الحالة:** قيد التنفيذ — Phase 0 مكتمل جزئياً  
**المبدأ الثابت:** مجاني 100% دائماً (Render Free + قناة تيليجرام كأرشيف)  
**المالك فقط:** القسم `/admin-tools` محمي بـ isOwner

---

## الأفكار المختارة للتنفيذ (من التحليل العميق)

### أولوية عالية (Phase 1 – الأساسي القوي)
1. **قناة تيليجرام كقاعدة بيانات دائمة (Zero-DB Native Archive)**  
   - عند أول تحميل ناجح: إرسال الملف صامتاً إلى قناة الأرشيف + حفظ `file_id` + الرابط الأصلي في نص الرسالة أو caption.  
   - عند طلب لاحق لنفس الرابط: البحث/الكاش → إعادة إرسال فورية بدون yt-dlp.  
   - يحل مشكلة Ephemeral Storage على Render Free تماماً.

2. **واجهة إيقاظ ذكية (Smart Cold-Start UX)**  
   - رسالة فورية: "محرك البوت يستيقظ من النوم العميق... ثوانٍ ويجهز طلبك".

3. **الوظائف الأساسية المتفوقة**  
   - يوتيوب (Shorts + عادي) + تيك توك (بدون علامة) + إنستغرام + تويتر/X + بينتيريست + ريديت وغيرها.  
   - اختيار الجودة + استخراج MP3.  
   - زر إضافي: إرسال كرسالة صوتية (OGG/Opus PTT).  
   - معاينة صورة + عنوان + مدة.

4. **تقطيع ذكي / رابط بث مؤقت (لحل حد 50MB)**  
   - < 50MB → إرسال عادي.  
   - أكبر → تقطيع بـ ffmpeg إلى أجزاء ~3 دقائق أو توليد رابط بث مؤقت خفيف.

5. **نظام أعلام الميزات المدفوعة (Feature Flags)**  
   - من اليوم الأول: بنية جاهزة لجعل أي ميزة مدفوعة بضغطة (جودة أعلى، بدون حد يومي، أدوات متقدمة...).

### أولوية متوسطة (Phase 2)
6. **ملخص الترجمة الذكي (Subtitle Summarizer)**  
   - سحب الترجمة → ملخص بـ 3 نقاط رئيسية (extractive بسيط أولاً).

7. **وضع المجموعات الاحترافي**  
   - منع الروابط المتكررة، حذف رسالة الرابط الأصلي بعد الإرسال، إعدادات للمشرفين.

8. **Cookie Pooling**  
   - رفع عدة ملفات cookies.txt وتدويرها لتجنب الحظر.

9. **الموجز العام الاختياري (Telegram Mini App Feed)**  
   - اختياري على مستوى البوت + يمكن للمستخدم إلغاء مشاركة محتواه الخاص.  
   - كل شيء يظهر في قناة الأرشيف بغض النظر عن خيار الموجز.

### أولوية لاحقة / تمايز (Phase 3)
10. لقطات التشويق الأساسية (Highlights)  
11. محول بسيط إلى ملصق/GIF  
12. تحسينات إضافية حسب الاستخدام الفعلي

## الجدولة التنفيذية

| المرحلة | المحتوى | الحالة |
|---------|---------|--------|
| **Phase 0** | صفحة `/admin-tools` + منشئ البوت + هيكل الخدمة + وثيقة الخطة | قيد التنفيذ الآن |
| **Phase 1** | بوت أساسي يعمل (تحميل + كاش قناة + إيقاظ + جودة + صوت + PTT) | التالي |

## البنية التقنية المختارة (مجانية دائماً)

- **واجهة الإدارة:** Next.js على Vercel (الصفحات الحالية).
- **عامل التحميل:** خدمة Python منفصلة على **Render Free** (yt-dlp + aiogram أو python-telegram-bot + ffmpeg).
- **التخزين الدائم:** قناة تيليجرام خاصة (file_id + رابط) — لا SQLite محلي، لا Turso إجباري في البداية.
- **الكاش السريع في الذاكرة:** dict بسيط + إعادة بناء من القناة عند الاستيقاظ إن لزم.
- **التوكنات والأسرار:** متغيرات بيئة فقط على Render — لا تُحفظ في GitHub أبداً.

## ملاحظات أمان وتشغيل
- التوكن الذي قدمه المالك **لن يُرفع أبداً** إلى المستودع.
- البوت يبدأ في وضع المالك فقط (whitelist) ثم يُفتح تدريجياً.
- كل ميزة جديدة تُبنى مع العلم أنها قد تصبح مدفوعة لاحقاً (feature flag).
