# Computer banks (private storage of each user+model computer session)

Source of truth for the bank network of the computer hub (`ai-system/modelscope-media/computer_banks.py`, reached by the `box` tool with `action="bank"`).
A bank is a named, private, content-addressed store inside one user+model session: nothing is shared between sessions, and no external storage is used.

- **Storage:** every object is compressed (zlib) and stored once under its SHA-256, so the same bytes in two banks take the space of one (`deduplicated: true` on the second put). A bank item is a name, a kind, optional metadata and, for text, a search index.
- **Limits:** 32 GB per session workspace (`COMPUTER_QUOTA_GB`), 512 MB per object, 2 MB for inline `content`; the hub host keeps a free-disk reserve (`COMPUTER_BANK_FREE_RESERVE_GB`, default 2 GB) and a write or restore that would break it is refused. A restore is written to a temporary file, checked against the stored size and SHA-256, then moved into place.
- **Actions (`bank_action`):** `list` (paginated: `limit`, `offset`), `create` (`bank`, `category`, `description`), `put` (`source_path` or `content`, `name`, `kind`, `metadata`), `get` (`item_id`; text comes back inline, a binary item needs `output_path`), `search` (Arabic and English text index; `include_related=true` follows links), `delete` (an item; its object goes when no item uses it), `drop` (a whole bank, needs `confirm=true`; the default `workspace` bank cannot be dropped), `link` (`bank`, `target_bank`, `relation`, `note`), `related`, `stats`, `gc` (removes stored objects no item points to).
- **Other tools added with the banks:** `computer_apps` (inventory of the optional workstation packages: office, Arabic OCR/PDF, data/Jupyter/DuckDB, Inkscape, GIMP, Audacity), the desktop's `pointer`, double-click, drag, mouse-button and clipboard actions, and the browser's real tabs, uploads/downloads, form controls, console/network diagnostics and local-preview check (a preview of a server started inside the same session; private networks and the metadata address stay blocked).
- **Hub revision:** `computer-hub-16gb-2026-11-22-r10-banks` (the deploy workflow and the preflight check this exact string).
