بديلاً عن Issue #1 الذي بدأ النقاش فيه. السبب التقني: منصة Claude لا تستطيع جدولة
فحص دوري لتعليقات Issue عادي (قيد في تمرير أدوات GitHub للمهام المجدولة)، لكنها
تستطيع الاشتراك في أحداث Pull Request وتصلها تلقائياً فور حدوثها (تعليق، دفعة
كود جديدة) — لذلك هذا PR هو مكان النقاش المستمر من الآن، لا Issue #1.
