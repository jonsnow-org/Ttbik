# حزمة صور زنوبيا (مسودات أولية للتحسين)

هذه الصور **مسودات رسمتُها بالكود** لتُحسَّن بيدك أو بأدواتك. اجعلها أجمل ثم أعدها إليّ لأحوّلها إلى صور متحركة.

## قواعد عامة عند التحسين
1. **احتفظ بنفس المقاس والنسبة** لكل صورة (مكتوب أدناه).
2. **لا تكتب نصوصًا داخل الصورة** (أسماء أو ألقاب أو أرقام). أضيفها أنا بالكود لتكون عربية وإنجليزية قابلة للتحديث. في المسودات نصوص مؤقتة فقط.
3. أعد كل صورة **PNG بخلفية شفافة للشخصية** إن أمكن، و**الخلفية في ملف منفصل**. وإن أمكنك: طبقة للذهب (التاج والحلي) وطبقة للجواهر وطبقة للوجه. الطبقات هي ما يجعل الحركة متقنة.
4. **الحقوق:** لا تنسخ صور متاحف أو مصورين دون ترخيص. أقدم صورة موثقة لها على عملات سكّتها سنة 272 (أنطاكية والإسكندرية)، وصورها مثل تاج مزيّن (diadem) وثوب. لم أجد تمثالًا مؤكد النسبة إليها. **أي تمثال تقصده؟** أرسل لي صورته أو رابطه لأتحقق من ترخيصه.
5. روح الصورة: ملكة جميلة وقوية، ذهب وتاج، بلا مبالغة عنف.
