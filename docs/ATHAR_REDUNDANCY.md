# أثر: كيف تبقى الرموز حيّة بألوانها وحركتها وإن غابت خوادمنا

## الطبقات (من الأمتن إلى الأخف)
1. **السلسلة (TON):** الرمز وملكيته وسجل أصحابه ونقوشه. لا تعتمد على أي خادم.
2. **Arweave (دائم):** صور المستخدمين والذهبي والخاص، و**العارض الحي** `athar/viewer/viewer.html` (24 كيلوبايت، رقمه في `PERMANENT_ID.txt`). ملف واحد بلا خادم: يرسم وردة الرمز كاملةً (دوران، وميض، هالة، ذكرى اليوم) من أرقام الرمز نفسها في العنوان `#i=..&t=..&s=..&g=..&h=..&e=..&o=..`. يظهر في الرمز كرابط «عرض حي دائم»، وفي البيانات كـ `animation_url`.
3. **مرآة Vercel (الموقع الرئيسي):** `/api/athar/img|m|collection` من الشيفرة نفسها (`athar/web/lib/handlers.ts`). تسأل خادم Oracle أولاً (فتسري قائمة الإزالة القانونية هناك)، وتجيب بنفسها إن لم يردّ خلال 4 ثوانٍ.
4. **خادم Oracle:** الأساس.
5. **Render (اختياري):** `render.yaml` في جذر المستودع، نفس صورة Docker.

## الأهم: عنوان البيانات في العقد
يُكتب `BASE_URI` في العقد عند الإطلاق (الأول فوري، وكل تغيير بعده بمهلة إشعار 48 ساعة). لذلك نجعله **عنوان مرآة Vercel** لا عنوان Oracle:
`NEXT_PUBLIC_ATHAR_META_BASE=https://<موقع-vercel>/api/athar`
فإن سقط Oracle تستمر الصور والبيانات من Vercel تلقائياً بلا أي معاملة على السلسلة. (عنوان المجموعة المشتق يتغيّر بتغيّر هذا العنوان، فيُحدَّد قبل الإطلاق ولا يُغيَّر.)

## إعدادات تُضاف مرة واحدة (لا أستطيع إضافتها بنفسي)
في **Vercel > Settings > Environment Variables** للموقع الرئيسي:
- `ATHAR_PRIMARY` = عنوان خادم أثر على Oracle
- `NEXT_PUBLIC_ATHAR_META_BASE` = `https://<موقع-vercel>/api/athar`
- `NEXT_PUBLIC_SITE_URL` = عنوان خادم أثر، `ATHAR_ADMIN` = عنوان محفظة الإدارة العام، `NEXT_PUBLIC_TON_NETWORK` = `mainnet`
(الصور تعمل بلا أي إعداد؛ البيانات `/m/` تحتاج هذه لتجيب وحدها حين يغيب Oracle.)
وفي Oracle: السطر `ATHAR_META_BASE=https://<موقع-vercel>/api/athar` في ملف `.env`.

## الباب الأمامي الدائم: Cloudflare Worker (قبل الإطلاق)
عنوان البيانات المكتوب في العقد لا يُغيَّر إلا بإشعار 48 ساعة، لذلك يجب أن يكون **عنواناً لا يعتمد على مضيف واحد**. الحل: Worker على حساب Cloudflare (مجاني، ملك صاحب الحساب، عنوانه `https://<الاسم>.<الحساب>.workers.dev`):
1. يسأل خادم Oracle أولاً، وإن لم يجب خلال 4 ثوانٍ يسأل مرآة Vercel، وإن سقط الاثنان يقدّم **آخر نسخة جيدة** حفظها (حتى 7 أيام).
2. الشيفرة: `cloudflare/athar-front-worker.js` (جُرِّبت محلياً: الرد الحي، والتحويل إلى Vercel، والنسخة المحفوظة، و503 عند غياب كل شيء).
3. **النشر بالربط مع المستودع (الأفضل: يتحدّث وحده عند كل دمج على الرئيسي):** في Cloudflare اختر Workers & Pages > Create > Import a repository (Connect to Git) > ثبّت تطبيق Cloudflare على حساب `jonsnow-org` واختر «Only select repositories» ثم `Ttbik` فقط > اختر المستودع > الاسم `athar-meta` > Root directory = `cloudflare/athar-front` > Production branch = `main` > أمر النشر `npx wrangler deploy` > Save and Deploy. (ملف الإعداد `cloudflare/athar-front/wrangler.jsonc`.)
   **النشر اليدوي (بديل بأربع نقرات)**: Cloudflare > Workers & Pages > Create > Create Worker > سمِّه `athar-meta` > Deploy > Edit code > الصق محتوى الملف > Deploy. انسخ العنوان.
4. يوضع العنوان في ثلاثة أماكن بالقيمة نفسها: ملف `deploy/oracle/agent/ATHAR_META_BASE` (أضعه أنا)، ومتغير Vercel `NEXT_PUBLIC_ATHAR_META_BASE`، ثم الإطلاق. (عنوان المجموعة المشتق يتغير بتغيّره، فيُحسم قبل أول إطلاق.)
5. بعد ذلك: سقوط Oracle أو Vercel أو الاثنين لا يغيّر شيئاً للمستخدم، ولا يلزم أي معاملة على السلسلة.

## النسخ الاحتياطي الأسبوعي للمشروع
كل أسبوع يأخذ Oracle نسخة كاملة من مصدر المشروع (كل الفروع والوسوم في ملف git bundle واحد) في `/var/backups/ttbik/repo-latest.bundle`، ولا تُستبدل النسخة القديمة إلا بنسخة جديدة سليمة. تظهر نتيجتها في تقرير Oracle (`backup.repo`). الصور والبيانات اليومية (قاعدة البيانات ونسخ أثر) لها نسخها اليومية كما هي. متغيرات Vercel لا يمكن نسخها آلياً (سرّية)، وقائمتها مكتوبة في هذا الملف.

## القيم النهائية (2026-10-05)
- الباب الأمامي: `https://athar-meta.jonsnowx1r.workers.dev` (Worker `athar-meta` على حساب Cloudflare، يُنشر من المستودع).
- `deploy/oracle/agent/ATHAR_META_BASE` = العنوان أعلاه، ومتغير Vercel `NEXT_PUBLIC_ATHAR_META_BASE` = العنوان نفسه.
- الـ Worker يقدّم نسخة حديثة محفوظة فوراً (5 دقائق للبيانات، ساعة للصور) ليحمي الخادم وواجهة الشبكة العامة حين تطلب سوق رموزاً كثيرة معاً.

## الفحص
`/api/ops/athar-health` على الموقع الرئيسي: يفحص الخادم والمرآة والعارض على بوابتي Arweave، ويقول `alive` إن بقيت الطبقات كافية.

## ما لا يمكن ضمانه
- الرموز المصكوكة قبل هذا الإعداد وصورتها مولّدة بالكود: تبقى حيّة ما بقيت مرآة أو خادم يرسمها (الشيفرة كلها في المستودع)، أو عبر العارض الحي الدائم.
- قائمة الإزالة القانونية محفوظة على Oracle فقط؛ المرآة لا تراها حين يغيب Oracle.
