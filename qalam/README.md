# Qalam (قلم)

نموذج أصلي بالكامل (أوزان عشوائية الابتداء) أكبر من OneCore: ≈132.6M معامل مخزَّن مقابل 57,579,201، بحساب نشط أقل لكل رمز بفضل الخبراء المتفرقين. التحليل والتصميم: [`docs/DESIGN.md`](docs/DESIGN.md).

- قاموس موحّد (نص + رموز خاصة + صورة + صوت + حركة) برموز وكيل أصلية.
- بلوكات متكررة مشتركة، انتباه GQA مع RoPE وكاش K/V، وMoE (8 خبراء، أعلى 2).
- T-LDM أصلي: ضاغط متعلَّم، تفكير كامن بالبلوكات نفسها، كاتب انتشار يقرأ البادئة من الكاش.
- فك تخميني ذاتي مطابق للفك الجشع حرفيًا.
- مشغّل أدوات بقائمة مسموحة (لا ينفّذ أي نص مولَّد)، ونقاط تدريب ذرّية بسلالة.

تشغيل الاختبارات: `pip install torch pyyaml pytest && cd qalam && python -m pytest -q`

لا يستورد من شام ولا نوفا ولا OneCore (اختبار استقلال في CI). لم يُدرَّب على بيانات حقيقية بعد.
