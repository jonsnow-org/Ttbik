# شام AI (Sham AI) — الذكاء الاصطناعي والتقنية والخدمات الرقمية المتكاملة (تكلفة تشغيل = 0$)

منصة كاملة لبيع خدمات وأدوات رقمية (بوتات تليجرام، أدوات ذكاء اصطناعي، قوالب أتمتة
ومواقع) مع تجربة تفاعلية حقيقية لكل خدمة، وتسليم فعلي حقيقي (لا روابط وهمية)،
ونظام طلب/دفع/موافقة شبه آلي — بدون أي تكلفة استضافة أو اشتراك.

## البنية التقنية (كلها Free Tier)

| الطبقة | الخدمة | لماذا مجانية |
|---|---|---|
| الاستضافة والدومين | **Vercel** (`your-app.vercel.app`) | خطة Hobby مجانية تماماً لمشاريع Next.js |
| قاعدة البيانات | **Supabase** (Postgres) | خطة Free تكفي آلاف الطلبات شهرياً |
| الذكاء الاصطناعي | **Groq API** (نموذج Llama 3) | مفتاح مجاني بدون بطاقة بنكية |
| القوالب/الأكواد المُسلَّمة | نفس مستودع GitHub هذا (`templates/`) | لا حاجة لأي مستودع أو حساب خارجي |
| الإشعارات والموافقة | لوحة تحكم داخل الموقع (`/admin`) | لا حاجة لأي خدمة خارجية |
| بديل الإشعارات (اختياري) | **Telegram Bot API** | مجاني، لكن غير مفعّل افتراضياً حالياً |

> **ملاحظة**: تليجرام مُهيّأ بالكامل في الكود لكنه **اختياري** — إن لم تُضِف
> `TELEGRAM_BOT_TOKEN` فالموقع يعمل بكامل وظائفه معتمداً فقط على لوحة `/admin`.

## الأقسام والخدمات (قابلة للتعديل من قاعدة البيانات مباشرة)

1. **🤖 بوتات تليجرام** — بوت رد آلي ($7)، بوت إدارة طلبات ($15)، بوت أسئلة شائعة ($5)
   — تسليم فعلي: كود حقيقي جاهز للتشغيل في [`templates/`](./templates).
2. **🌐 الترجمة والذكاء الاصطناعي** — مترجم ذكي ($3)، تلخيص نصوص ($4)، مساعد رد على العملاء ($10)
   — تسليم فعلي: رابط أداة كاملة الوصول (بدون حد أحرف) يُفتح تلقائياً برمز الطلب.
3. **⚙️ الأتمتة والمواقع** — منشئ صفحات هبوط ($12)، قوالب أتمتة مجانية بديلة عن Zapier ($9)، مولد فواتير ($6)
   — تسليم فعلي: كود حقيقي جاهز للتشغيل في [`templates/`](./templates).
4. **🎨 المحتوى بالذكاء الاصطناعي** — منشورات سوشيال ميديا ($3)، كاتب مقالات ($8)، أوصاف منتجات ($5)
   — تسليم فعلي: رابط أداة كاملة الوصول.

كل خدمة تحتوي **تجربة تفاعلية حقيقية** تعمل مباشرة في المتصفح قبل الشراء:
- خدمات الذكاء الاصطناعي: تجربة حقيقية عبر Groq API المجاني (محدودة بـ 500 حرف كتجربة، بدون حد في النسخة المدفوعة).
- بوتات تليجرام: محاكاة محادثة تعمل بالكامل في المتصفح.
- الأتمتة والمواقع: معاينة حية تفاعلية (Live Preview).

## دورة الطلب والدفع (شبه آلية)

1. العميل يفتح صفحة الخدمة، يجرّب النسخة المحدودة، ثم يضغط "اطلب الآن".
2. تظهر له بيانات الدفع (تحويل بنكي أو USDT) → يحوّل → يضغط "تم الدفع ✅" → يدخل اسمه وبيانات التواصل ورقم/اسم عملية التحويل.
3. يُنشأ الطلب بحالة `pending`، ويظهر فوراً في لوحة `/admin` (تحديث كل 8 ثوانٍ)،
   وإن كان تليجرام مفعّلاً يصلك أيضاً تنبيه فيه بزرين **[موافقة ✅] [رفض ❌]**.
4. بمجرد الموافقة، يُسلَّم للعميل تلقائياً:
   - لخدمات الذكاء الاصطناعي: رابط الأداة الكاملة `/tools/<tool>?order=<code>` (يُنشأ ديناميكياً، غير قابل للتخمين عملياً).
   - لخدمات البوتات/الأتمتة: رابط القالب الحقيقي داخل [`templates/`](./templates) في هذا المستودع.
   - يظهر في صفحة تتبع الطلب `/order/[code]` التي تتحدّث كل 5 ثوانٍ تلقائياً.

## خطوات التشغيل (كل الخطوات هنا مجانية 100%)

### 1) قاعدة البيانات — Supabase
1. أنشئ حساباً مجانياً على supabase.com (يمكن تسجيل الدخول مباشرة بحساب GitHub — بدون كلمة مرور جديدة).
2. من SQL Editor نفّذ محتوى الملف `supabase/schema.sql` كاملاً (ينشئ الجداول + سياسات RLS + بيانات تجريبية).
3. من Project Settings → API خذ: `Project URL`, `anon public key`, `service_role key`.

### 2) الذكاء الاصطناعي — Groq (مجاني)
سجّل في console.groq.com (بدون بطاقة بنكية) وأنشئ `GROQ_API_KEY` من قسم API Keys.

### 3) النشر — Vercel
1. سجّل دخول بحساب GitHub (نفس الحساب الذي يملك هذا المستودع) على vercel.com.
2. Import Project → اختر هذا المستودع.
3. أضف كل المتغيرات الموجودة في `.env.example` داخل Vercel → Settings → Environment Variables
   (بيانات الحساب البنكي/USDT تُدخل هنا فقط، **ولا تُكتب أبداً داخل ملفات الكود**).
4. Deploy — ستحصل على دومين مجاني `xxx.vercel.app`. اجعل `NEXT_PUBLIC_SITE_URL` مطابقاً له.

### 4) بوت تليجرام (اختياري — يمكن تخطيه حالياً)
1. تحدث مع `@BotFather` → `/newbot` → احصل على `TELEGRAM_BOT_TOKEN`.
2. تحدث مع `@userinfobot` لمعرفة `chat_id` الخاص بك → `TELEGRAM_ADMIN_CHAT_ID`.
3. اختر أي نص عشوائي ليكون `TELEGRAM_WEBHOOK_SECRET`.
4. بعد النشر، فعّل الـ webhook مرة واحدة بزيارة (استبدل القيم بين `<>`):
   ```
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<SITE_URL>/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
   ```

### 5) التشغيل محلياً (اختياري للتجربة)
```bash
npm install
cp .env.example .env.local   # ثم عبّئ القيم
npm run dev
```

## الأمان

- جدول `orders` **غير قابل للقراءة العامة** (لحماية بيانات العملاء)؛ تتبع الطلب يتم عبر
  دالة SQL محصورة (`get_order_public_status`) تُعيد فقط الحقول غير الحساسة.
- كل عمليات الموافقة/الرفض والوصول لأدوات الذكاء الاصطناعي الكاملة تمر عبر
  `SUPABASE_SERVICE_ROLE_KEY` من كود السيرفر فقط، ولا تصل أبداً للمتصفح.
- لوحة `/admin` محمية بكلمة مرور عبر `middleware.ts` وكوكي `httpOnly`.
- طلبات الـ Telegram webhook (إن فُعّلت) تُتحقّق عبر `secret_token`.
- **بيانات الحساب البنكي/USDT حساسة**: تُدخل فقط كمتغيرات بيئة في لوحة الاستضافة
  (Vercel)، ولا تُكتب إطلاقاً داخل ملفات الكود التي تُرفع لـ GitHub.

## ما أحتاجه منك فقط

هذه الخطوات الوحيدة التي لا يمكنني تنفيذها بنفسي لأنها تتطلب تحقق بريد إلكتروني
لا أملك وصولاً إليه:

1. **تسجيل الدخول بحساب GitHub** (بضغطة واحدة، بدون كلمة مرور جديدة) في: Supabase, Vercel.
2. **مفتاح Groq المجاني** من console.groq.com.
3. لصق القيم الناتجة في متغيرات البيئة على Vercel.

بوت تليجرام غير مطلوب حالياً بناءً على طلبك — الموقع يعمل بكامل وظائفه بدونه عبر لوحة `/admin`.

كل شيء آخر (الكود، التصميم، المنتجات الفعلية القابلة للتسليم، منطق الموافقة،
التجارب الحية) جاهز بالكامل في هذا المستودع.
