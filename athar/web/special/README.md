# Special-date artwork

Put a picture here to give a historic date its own artwork instead of the generated one:

    1969-07-20.webp      (also .jpg or .png; at most 66 KB, any shape: it is shown whole inside the frame)

The date stays on the token as a small badge. The picture is stored permanently when the token is made.
The list of special dates is in `lib/seasons.ts` (HIST).
