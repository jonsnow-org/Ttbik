# نشر شام AI على Oracle

## الصورة العامة

```
تليجرام ──► Vercel (الباب الأمامي، يعمل دائماً)
                │
                ├─► Oracle   المحرك الأساسي لبوت الوسائط (يعمل دائماً)
                │      └─ إن تعذّر الوصول إليه خلال 10 ثوانٍ
                └─► Render   المحرك الاحتياطي (ينام عند عدم الاستخدام)
```

- لا يُحذف شيء: Vercel وRender يبقيان. الجديد هو Oracle فقط.
- التحويل بين المحركين تلقائي، والمستخدم لا يرى فرقاً. المحرك الاحتياطي يستلم الرسالة فقط عندما يفشل الأساسي، فلا تُعالَج الرسالة مرتين.
- حالة البوت (المستخدمون، الاشتراكات، الكاش) تُحفظ في قناة الأرشيف على تليجرام، فيقرؤها أي محرك يبدأ العمل.

## ما تفعله أنت (مرة واحدة، نحو 15 دقيقة)

### 1) إنشاء الجهاز على Oracle
Compute ← Instances ← Create instance:
- **Image:** Canonical Ubuntu 24.04 (أو 22.04) — نسخة **aarch64**.
- **Shape:** Ampere ← `VM.Standard.A1.Flex` ← **2 OCPU و12 GB** (هذا الحد الحالي للحساب المجاني).
- **Networking:** اترك «Assign a public IPv4 address» مفعّلاً.
- **SSH keys:** اختر Generate ثم **Save private key** واحتفظ بالملف.
- **Boot volume:** 100 GB (المجاني حتى 200 GB).
- إذا ظهرت رسالة `Out of capacity`: جرّب مجال توافر (Availability domain) آخر، أو أعد المحاولة بعد ساعات.

### 2) فتح المنفذين في Oracle
Networking ← Virtual Cloud Networks ← شبكتك ← Subnet ← Security List ← Add Ingress Rules:
- Source `0.0.0.0/0` ، Protocol `TCP` ، Destination Port **80**
- المثل للمنفذ **443**

### 3) الاتصال وتشغيل الإعداد
من جوالك (Termux أو Termius) أو حاسوبك:
```bash
ssh -i ملف_المفتاح.key ubuntu@عنوان_IP
curl -fsSL https://raw.githubusercontent.com/jonsnow-org/Ttbik/claude/free-services-marketplace-h6rwk2/deploy/oracle/bootstrap.sh | bash
```
السكربت يثبّت Docker ويفتح الجدار الناري ويسحب الكود وينشئ ملفات الإعداد. ثم يتوقف ويطلب منك ملء الإعدادات:
```bash
sudo nano /opt/ttbik/deploy/oracle/media.env
```
انسخ القيم نفسها من لوحة Render (Environment) لبوت الوسائط: `BOT_TOKEN` و`OWNER_ID` و`ARCHIVE_CHANNEL_ID` و`FEED_SECRET`، وأي قيمة اختيارية تستخدمها هناك (`YTDLP_COOKIES` أو `PROXY_URL`). **التوكن نفسه، لا تغيّره.**

ثم أعد تشغيل السكربت (آمن للتكرار):
```bash
curl -fsSL https://raw.githubusercontent.com/jonsnow-org/Ttbik/claude/free-services-marketplace-h6rwk2/deploy/oracle/bootstrap.sh | bash
```

### 4) التحقق
```bash
sudo bash /opt/ttbik/deploy/oracle/status.sh
```
ثم أرسل `/start` لبوت الوسائط. وأخبرني بالنتيجة.

> العنوان العام يُحدَّد تلقائياً بالشكل `عنوان-IP.sslip.io` (DNS مجاني بلا تسجيل)، والشهادة تُستخرج تلقائياً.

## المراحل

| المرحلة | ماذا يعمل على Oracle | المخاطرة |
|---|---|---|
| **1 — الآن** | محرك بوت الوسائط (أساسي) | منخفضة: Render يبقى احتياطاً |
| **2 — لاحقاً** | + نسخة تجريبية من الموقع `docker compose --profile site up -d --build` | منخفضة: لا تستقبل أي زيارات ولا ويبهوك |
| **3 — بعد موافقتك** | نقل الموقع فعلياً + `--profile cron` | متوسطة، انظر أدناه |

### قبل المرحلة 3 (النقل الفعلي)
1. **الدومين:** عنوان `sslip.io` يصلح للمحرك، لكنه سيئ للموقع نفسه: شبكات الإعلانات (Adsterra وMonetag) تتحقق من الدومين، ومحركات البحث تتعامل معه كدومين مشترك. ولا يمكن توجيه `ttbik.vercel.app` إلى Oracle. لذلك قبل النقل الكامل نحتاج دومين تملكه. وإلى أن يتوفر يبقى Vercel واجهة الموقع العامة، ويعمل Oracle محركاً ونسخة جاهزة.
2. **Cron:** لا تُشغَّل المهام المجدولة على Oracle إلا بعد تعطيلها في Vercel، وإلا تعمل كل مهمة مرتين (منشورات مكررة في القناة، وفحص إيداعات TON مرتين).
3. **الويبهوك:** عنوان ويبهوك كل بوت مستضاف يُسجَّل عند إنشائه. عند النقل يجب إعادة تسجيلها (سأجهّز أداة لذلك).
4. **التراجع:** إعادة المسار إلى Vercel كافية: لا يُحذف شيء هناك.

## المتطلبات (قائمة مختصرة)
- جهاز Oracle: Ubuntu aarch64، **2 OCPU / 12 GB**، عنوان IPv4 عام، المنفذان 80 و443 مفتوحان.
- قيم بوت الوسائط من Render (للمرحلة 1).
- قيم الموقع من Vercel (للمرحلة 2+): انظر `.env.example` — كل متغير مذكور فيه.
- ذاكرة: محرك الوسائط حتى 4 GB، والموقع حتى 4 GB (من أصل 12 GB).

## تنبيهات مهمة
- **الاسترداد عند الخمول:** Oracle قد تسترد الجهاز المجاني إذا بقي استخدامه منخفضاً (أقل من 20% للمعالج والشبكة والذاكرة) أسبوعاً كاملاً. لن نضيف أي ضجيج اصطناعي لتفاديه. إن حدث ذلك فالمحرك الاحتياطي (Render) يستلم تلقائياً. وترقية الحساب إلى «الدفع عند الاستخدام» تزيل الخطر مع بقاء الموارد مجانية، لكنها تتطلب بطاقة.
- **حد 50 MB:** تليجرام يقبل رفع ملفات حتى 50 MB عبر واجهته السحابية. المحرك يختار أكبر نسخة تناسب هذا الحد. رفع الحد إلى 2 GB يتطلب خادم Bot API محلياً، وهذا يغيّر طريقة عمل البوت مع Vercel، فلا نفعله الآن.
- **حظر العناوين:** تيك توك ويوتيوب قد يحظران عنوان Oracle كما حظرا Render. هذا ليس من المحرك، وعلاجه كوكيز (`YTDLP_COOKIES`) أو وكيل (`PROXY_URL`).
- **التحديث لاحقاً:** `sudo bash /opt/ttbik/deploy/oracle/update.sh` (أضف `--profile site` إن كان الموقع يعمل هنا).
