## 3. مفاتيح التشغيل والإيقاف
- **نشر الفيديو:** وجود الملف `promo/PUBLISH_ON` يفعّل النشر المجدول. يُحذف لإيقافه. أو `publish=0|1` عند تشغيل `promo-remotion` يدوياً.
- **تغذية الإطلاقات:** `COINS_LAUNCH_FEED=1` في إعدادات الموقع (متغير بيئة، لا تُطبع قيمه).
- **أسرار:** `CRON_SECRET` موجود في GitHub Actions وVercel ويجب أن يتطابقا (الخطأ الشائع: «does not match»). **لا يُقرأ ولا يُطبع ولا يُنقل.**
- حدّ نشر Vercel المجاني: لا دفع متكرر إلى الفرع الافتراضي `claude/free-services-marketplace-h6rwk2`؛ التجميع ثم دفعة واحدة.

## 4. القواعد الثابتة (أوامر المالك)
1. لا نشتري شيئاً: أدوات ومنصات مجانية فقط ولا إعلانات مدفوعة.
2. لا وعود بأرباح ولا تضليل في أي نص. النصوص تذكر المخاطر.
3. قناة العملات إنجليزية فقط. الفيديو العربي بالفصحى (ليس اللهجة).
4. لا ترويج لـ Nova AI، ولا لاسم «Sham» منفرداً في القناة العامة («شام AI» مسموح).
5. لا نجوم تلجرام (Stars) على صفحات منصة العملات.
6. لا إعلانات متطفلة، ولا إعلانات خارجية على شاشات توقيع المحفظة.
7. النصوص العامة: الإنجليزية أولاً ثم العربية.
8. لا أسرار في أي ملف أو تعليق. لا تُلمس مجلدات `CLAUDE.md` المحظورة إلا بأمر المالك للجلسة المعنية.

## 5. صلاحيات المشرف (ضُمنت له كلها، بحذر)
**يفعلها مباشرة:**
- قراءة كل شيء: Actions وReleases والقنوات والموقع وسجل الأخطاء وبلاغات `auto-error`.
- تشغيل أي workflow ترويجي بوضع المعاينة `dry` (لا ينشر شيئاً).
- إعادة تشغيل المهام الفاشلة **مرة واحدة** للأنظمة آمنة التكرار فقط (فيديوهات المشاريع، فرز الأخطاء). المشرف الآلي يفعل ذلك وحده؛ أما `channel-post` و`coins-channel-post` و`promo-remotion` فلا تُعاد تلقائياً لأن إعادتها قد تكرر منشوراً.
- فتح وتحديث وإغلاق Issues (تقرير المشرف، `auto-error`).
- إصلاح الأخطاء البرمجية الصغيرة في ملفات الترويج (`src/lib/channel*.ts` و`coinsChannel.ts` و`announce.ts` و`promo/**` و`scripts/promo/**` وworkflows الترويج) عبر PR مع اختبار ودمج في `main`؛ والدفع إلى الفرع الافتراضي دفعة واحدة (حدّ Vercel).

**يحتاج موافقة المالك أولاً:**
- أي نشر يدوي فعلي (`announce` بلا `dry`)، تفعيل `COINS_LAUNCH_FEED`، إنشاء أو حذف `promo/PUBLISH_ON`.
- إضافة قناة أو حلقة أو تغيير جدول أو سياسة المحتوى أو أي قاعدة في القسم 4.
- أي إنفاق مال أو أداة مدفوعة.

**ممنوع دائماً:**
- قراءة أو طباعة أو نقل أي سر (`CRON_SECRET` وتوكنات البوتات وغيرها).
- لمس `athar/**` و`cloudflare/**` و`deploy/oracle/**` وبقية القائمة المحظورة في `CLAUDE.md`.
- الدفع المباشر إلى `main` أو `claude/athar-work`، أو force-push.
- حذف منشورات أو قنوات المالك، أو أي وعد بربح.

**التصعيد:** فشل متكرر مرتين متتاليتين، أو سبب غير معروف، أو أي شيء في خانة «يحتاج موافقة»: يُعلَّق على الـ Issue بعلامة `needs-owner` وتُترك المسألة للمالك أو للمنظِّم.

## 5.1 قائمة المشرف (يومياً، للمتابعة فقط)
1. **التقرير:** افتح الـ Issue ذا العلامة `promo-supervisor` (يتحدّث تلقائياً مرتين يومياً). ثم تحقق يدوياً مما يلي:
2. **التنفيذ:** في GitHub Actions: آخر تشغيل لكلٍّ من `channel-post`, `coins-channel-post`, `promo-remotion` ناجح (أخضر). فشل = Issue `auto-error` يُحل أو يُبلَّغ.
3. **الظهور:** افتح القناتين وتأكد أن آخر منشور حديث (العامة: خلال ~3 ساعات نهاراً، العملات: خلال ~6 ساعات نهاراً). قناة العملات بلا حرف عربي.
4. **الفيديو:** آخر Release `promo-ep-N` موجود ومفتوح، وإن كان `PUBLISH_ON` موجوداً وصل إلى القناة المقصودة.
5. **الموقع:** الصفحات العامة تعمل (الرئيسية، `/zenobia/coins.html`) وبلا إعلانات في الصفحات المحظورة أعلاه.
6. **الأخطاء:** إصلاح ما سببه إعداد أو تشغيل (عادةً CRON_SECRET أو رمز بوت)، أما أي تعديل في الكود أو المحتوى فيُرفع إلى المنظِّم.
7. سجّل الملاحظة في القسم 7 أدناه (سطر واحد).

## 6. أعطال معروفة وحلولها
| العَرَض | السبب والحل |
|---|---|
| `CRON_SECRET ... does not match` | القيمة في GitHub مختلفة عن Vercel. المالك يوحّدها. |
| منشورات القناة العامة توقفت | فحص `channelPublisher` (فلتر الكلمات، قاعدة «ai» استُثني منها «شام AI») وأن الاختيار المحظور يُعلَّم كمقروء. |
| فيديو إنجليزي فيه صور عربية | مسجّل الشاشة يجب أن يبدأ من صفحة المنصة (`home:false`, `rec=1`)، لا من رئيسية «شام» العربية. |
| الترجمة تنقطع وسط الجملة | علامات الترقيم تسقط من TTS: `restore_punctuation` في `finalize_words.py`. |
| الفيديو لم يصل إلى القناة | `promo/PUBLISH_ON` غير موجود أو `publish=0`، أو الملف أكبر من 48MB، أو توكن البوت مفقود. |
| نشر Vercel «rate limited» | حد الخطة المجانية: انتظر 24 ساعة ثم دفعة واحدة. |
